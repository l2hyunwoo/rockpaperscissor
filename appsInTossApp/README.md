# 앱인토스 가위바위보 앱

공통 게임 화면에 익명 사용자 키·공유·호스트 이벤트·안전 영역·화면 닫기를 연결한 Compose 웹앱입니다.

[공통 UI](../shared-ui/README.md)와 [공통 core](../shared-core/README.md)를 사용합니다. 기록은 브라우저 localStorage에 익명 사용자 키별로 저장합니다. 키를 얻지 못하면 기록을 저장하지 않고 게임은 계속 진행합니다.

뒤로 가기 이벤트는 종료 확인 모달을 열고, 확인하면 호스트 화면을 닫습니다. 홈 이벤트는 모달을 닫습니다. 개발용 mock은 뒤로 가기 이벤트를 보내지 않으므로 같은 경로를 여는 `나가기` 버튼을 표시합니다.
