# 앱인토스 가위바위보 앱

공통 게임 화면에 익명 사용자 키·토스앱 Storage·햅틱·게임센터 프로필과 리더보드·공유·호스트 이벤트·안전 영역·화면 닫기를 연결한 Compose 웹앱입니다. 각 기능은 `Capability`로 지원 여부를 확인하고, 미지원이면 숨기거나 대체합니다.

[공통 UI](../shared-ui/README.md)와 [공통 core](../shared-core/README.md)를 사용합니다. 기록은 토스앱 Storage(미지원 시 localStorage)에 익명 사용자 키별로 저장합니다. 키를 얻지 못하면 기록을 저장하지 않고 게임은 계속 진행합니다.

화면의 `나가기` 버튼과 뒤로 가기 이벤트는 종료 확인 다이얼로그를 열고, 확인하면 호스트 화면을 닫습니다. 홈 이벤트는 다이얼로그를 닫습니다. 웹 리소스(폰트·손 이미지)를 미리 읽은 뒤 화면을 그립니다.
